Parsanol 0.4.0 simplified the surface and removed the last eager costs from position tracking.

## Unified `parse()` API

The specialized entry points collapsed into one:

- `parse_with_transform(g, i, cache)` → `parse(g, i, map)`
- raw atoms keep `parse_with_grammar(atom, i)`

## Lazy line/column

`Slice` carries `offset` and `content`; `line_and_column` is computed on demand and cached after first access — position info costs nothing unless you read it:

```ruby
result[:name].line_and_column # => [1, 7]
```

## Also in this release

- Ruby 4.0 support in the extension matrix
- WASM build fixes (the wasm target stays behind its feature flag)
