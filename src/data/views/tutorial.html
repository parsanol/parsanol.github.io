Parser Writing Tutorial

Learn to build parsers from scratch with Parsanol.

Introduction

A parser is a program that analyzes text according to a set of rules (grammar) and produces a structured representation of that text. Parsanol is a parser combinator library that lets you build parsers by combining smaller parsers together.

This tutorial will take you from zero to building real parsers.

Chapter 1: Basic Atoms

Atoms are the fundamental building blocks of parsers. They match specific patterns in the input text.

str() - Match Literal String

re() - Regular Expression

any() - Any Character

match() - Character Class

Chapter 2: Combinators

Combinators combine atoms (and other combinators) to build more complex parsers.

Sequence (then or >>)

Match multiple patterns in order.

Choice (or or |)

Try each alternative in order.

Repetition (repeat)

Match patterns zero or more times.

Optional (maybe)

Match a pattern zero or one time.

Chapter 3: Captures & Labels

Labels (.as)

Attach names to matched content for the parse tree.

Best Practices

1. Start Simple

Build your parser incrementally. Test each rule before combining them.

2. Handle Whitespace

Create a reusable `space?` rule and use it throughout your grammar.

3. Name Your Rules

Use `.as(:name)` to label captures for easier debugging.

4. Use Two-Stage Parsing

Separate parsing (syntax) from transformation (semantics).
